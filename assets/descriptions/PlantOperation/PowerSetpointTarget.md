Operator-entered target for reactor power as a fraction of rated full power. The demanded power setpoint ramps toward this target at the requested rate rather than stepping, which keeps rod motion and thermal gradients bounded.

The power control system automatically adjusts reactor power and power distribution through rod motion, boron concentration changes, and moderator temperature so the NSSS follows load with minimal operator interaction. A remote dispatch interface also exists in the reference design: it transmits computed power capability to the network dispatcher but acts as a permissive network so unsafe demands cannot be executed.
