Turbine operating state string - stopped, turning gear, rolling, synchronized/online, tripped, and similar named states.

Useful as a one-glance sanity check during maneuvers: state should always agree with stop valve position, breaker status, shaft speed, and steam pressures. Any disagreement - rolling with the stop valve shut, online below rated speed - means an interlock fired, an indication failed, or someone is about to have an interesting day. The named states mirror the physical sequence operators walk through, from turning gear warmup through roll, synchronization, and load.
