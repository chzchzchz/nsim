Acknowledges every currently active alarm at once instead of clicking rows individually. Acknowledgement stops the flashing/new state but does not remove the condition itself - the alarm clears only when its process variable returns to normal.

The annunciator philosophy follows the reference control room: alarm points are turned off by operator acknowledgement, so silence-all style actions are convenience wrappers over the same per-alarm reset path.
