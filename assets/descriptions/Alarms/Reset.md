Acknowledges a single alarm; the control body is the alarm ID string. You rarely type here - clicking the row in the annunciator panel sends Reset with that row's ID behind the scenes.

Acknowledgement semantics follow the reference control room: alarms are turned off by operator acknowledgement, meaning the audible and flashing states stop but the condition itself must clear on its own merits. If the process variable is still out of band when acknowledged, expect the alarm to reassert - repeated re-flashing of the same point after acknowledgement is a classic sign the operator silenced a symptom without addressing the cause.
