Acknowledges a single alarm; the control body is the alarm ID string. Push one ID at a time - typically via clicking the row in the alarm panel, which sends Reset behind the scenes.

As with all annunciator points, alarms are turned off by operator acknowledgement. If the underlying condition persists the alarm reactivates; acknowledgement only silences the present occurrence.
