Switchover of containment spray pump suction to the recirculation phase. Setting it aligns the pumps to draw from the containment sump instead of the spray storage tank, for the long-term cooling phase after the CSST inventory is spent.

The realignment is a valve lineup: sump isolation valves open, spray-pump suction isolation valves close, and spray additive stops flowing since borated NaOH is no longer needed on a recirculating loop. The reference makes this an operator action: "The recirculation mode of the CSS will be initiated manually by the operator." Watch the storage tank inventory run down toward empty; once it does, only the sump can feed the pumps.

Model note: the latch flips suction alignment directly and does not animate the individual valves C and D.
