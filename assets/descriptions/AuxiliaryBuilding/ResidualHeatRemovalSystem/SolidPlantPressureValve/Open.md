Modulating valve between the RHR pump discharge and the CVCS system that trims a water-solid primary back to the selected pressure: "a pressure control valve between the RHR and CVC systems which is set to maintain a selected pressure while charging makes up for any coolant contraction and losses."

In solid plant operations there is no pressurizer steam cushion, so inventory changes move pressure almost instantly. This valve is the relief half of that pair - [charging](AuxiliaryBuilding/ChemicalVolumeControlSystem/ChargingPumpRunning) is the makeup half - and whatever it passes shows up as [SolidPlantReliefFlow](AuxiliaryBuilding/ResidualHeatRemovalSystem/SolidPlantReliefFlow). Open it gradually: the same RHR flow that cools the core is the driving head here.
