Charging line flow into the RCS in gpm. Its floor is set by RCP seal injection requirements - the seals need cooling and lubrication flow whether anything else is happening, so charging never goes to zero while pumps run.

Watch it respond to pressurizer level error under automatic control: persistent deviation means either the program moved (heatup underway) or mass is escaping somewhere (leak). Together with [letdown](AuxiliaryBuilding/ChemicalVolumeControlSystem/LetdownFlow) it defines net inventory movement, which in an incompressible water system is another name for pressure trend.
