Automatic pressurizer level control: charging flow adjusts continuously to hold level at the programmed value, which varies with RCS average coolant temperature.

Under manual control the operator does this matching by hand - workable steady-state, tedious through heatup when the program itself is moving. Leave it automatic except when diagnosing level control faults.
