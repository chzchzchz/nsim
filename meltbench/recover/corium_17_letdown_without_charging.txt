# The avoid-corium sequence for corium_17: unlike the hot-leg
# break or SGTR, the letdown path is closable (a valve an
# operator can shut), so the recovery is a true recovery, not a
# no-closing probe. At 10 s close letdown, restore charging,
# unblock SI + Reset, and trip (fission off: the lumped clad
# anchor drops to decay heat). Validated via nsimrun -seconds
# 60/300/600: BreakDischarged pins at 750 gal (UncoveryFrac
# 0.0018), clad 1,001/1,065/1,107 F, OxidizedFrac 0,
# VesselFailed=false. The SI-block-only recovery without trip
# still latches at 300 s (untripped fission rides the clad
# anchor to 8,889 F); the trip is the decisive step. Contrast
# corium_14/16, where SI restore alone cannot outrun the break.
